# Gewinnen v0.3

Persönliche PWA für GitHub Pages.

## Update auf GitHub
Alle Dateien dieses Pakets gehören direkt in die oberste Ebene des Repositorys. `index.html` muss dort sichtbar sein.

Die App enthält geprüfte Fallback-Daten direkt in `app.js`. Dadurch werden auch dann Ergebnisse angezeigt, wenn `data/contests.json` fehlt oder nicht geladen werden kann.
